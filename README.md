# Između redova

Moderan responzivni web portal za projekat **„Između redova“**, posvećen mladima, čitanju, kreativnosti, kritičkom mišljenju i otvorenom dijalogu.

## Struktura

```text
izmedju-redova/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── script.js
├── assets/
│   ├── images/
│   └── icons/
└── README.md
```

## Tehnologije

- HTML5
- CSS3 (Grid, Flexbox, CSS variables, clamp, responsive layout)
- Vanilla JavaScript
- IntersectionObserver za diskretne reveal animacije

## Pokretanje

Otvori `index.html` direktno u modernom browseru ili pokreni lokalni server, npr. iz foldera projekta:

```bash
python -m http.server 8000
```

Zatim otvori `http://localhost:8000`.

## Fotografije

Fotografije iz originalnog Word dokumenta nisu korišćene. AI generisane fotografije iz prve verzije su uklonjene. Nova verzija koristi realne tematske fotografije sa Unsplash servisa putem njihovih CDN URL-ova.

Za prikaz fotografija potrebna je internet konekcija. Ako želiš potpuno offline verziju, fotografije se mogu naknadno preuzeti u `assets/images/` i putanje zamijeniti lokalnim putanjama.
